# SideStore source schema

`sidestore-source-schema.json` is vendored from the official
[SideStore/sidestore-source-types](https://github.com/SideStore/sidestore-source-types)
repository at commit `02d31fa6301deac10bae11e91e1316b656598882`.

The build validates every generated `source.json` against this Draft 7 schema
before it can replace the local output or be uploaded for GitHub Pages.
